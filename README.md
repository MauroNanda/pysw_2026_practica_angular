# TP Angular 2026

Práctica Angular — Programación y Servicios Web  
Facultad de Ingeniería, Universidad Nacional de Jujuy

## Contenido

- **Punto 1:** Slide personalizado de eventos
- **Punto 2:** Catálogo de productos con carrito de compras
- **Punto 3:** Juego de memoria
- **Parte 2:** Sistema de inscripción a cursos con servicios Angular

## Tecnologías

- Angular 17+
- Bootstrap 5
- TypeScript
- angular-datatables

## Instalación

```bash
npm install
ng serve
```

Abrir en `http://localhost:4200`
